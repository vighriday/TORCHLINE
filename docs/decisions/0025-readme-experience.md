# 0025 — A playable reading experience with inspectable proof

Accepted October 29, 2026 for the owner-requested README. This changes documentation and optional capture tooling, not the application architecture.

Use original self-contained SVG artwork, a small animated handoff illustration, opt-in actual gameplay GIF, native GitHub STL inspection and a searchable synthetic flight log. Lead with plain language and consequences; put setup and engineering behind disclosures. Generate current-rule examples from the real engine and check deterministic replay. Preserve the distinction between illustration, saved simulation, automated evidence and real Twitch acceptance.

The strongest alternative is a short text-only README with a video link. It is smaller but cannot demonstrate the owner's requested visual identity or an inspectable contribution-to-consequence example. A hosted interactive microsite offers more freedom but adds deployment, accessibility and availability dependencies before a judge understands the product. Avoid external badge/animation services and unsupported SVG scripting.

Optional Python generation dependencies are pinned separately from the application. GIF is chosen for inline motion because GitHub documents SVG animation as unsupported. Picture sources provide reduced-motion stills; collapsed content reduces reading load but does not guarantee deferred image transfer. The model is below GitHub's 10 MB limit and is not a print-ready solid.
