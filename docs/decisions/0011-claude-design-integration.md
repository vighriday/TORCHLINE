# 0011 — Integrate Claude Design through canonical presentation contracts

Accepted 2026-10-27. Retains React/Vite, Fastify, PostgreSQL, and the separation of gameplay, hosted episodes and custody.

The six supplied screens share an effective command-deck visual language. Their export runtime, client game simulator, sample creators, seven-node puzzle, timers, synthetic votes and demonstration raid animation cannot supply production state. Port the visual structure into typed React components. Keep every existing mutation, session, SSE stream and server capability check.

Use one shared Ark renderer across the bridge, archive and read-only broadcast view. SVG provides an accessible schematic and a permanent fallback. Lazy-load pinned Three.js for an optional cinematic rendering derived from the same seven physical systems, marks and resources. No React Three Fiber, game framework, remote runtime, postprocessing pipeline or client engine is needed. This revises D4's deferral of Canvas: supplied ship art now justifies an isolated renderer, while DOM/SVG retain all information and interaction.

Limit rendering to 30 frames per second, cap pixel ratio, suspend offscreen/hidden work, dispose GPU resources, and fall back on context loss. Respect reduced motion and default small screens to the schematic. Visual preferences never change a world. Show actual phase and host-controlled windows instead of invented countdowns. Overlay components expose no creator controls, simulator or operator setup.

Archive displays the bounded canonical event projection and persistent marks, with its limit explicit. Do not invent chapter snapshots, replay hashes, creator history or incoming-world previews that the API does not expose. Relay displays actual intent status and receiver consent; its animation cannot constitute raid proof. Broader paginated history and scoped incoming-world previews remain separate API work.

Original exports remain unchanged in the ignored local `frontend-design/` workspace. Version curated components, the source inventory and local licensed fonts. Do not publish duplicate uploads, prototype data or screenshots as runtime dependencies.

See [the design integration review](../design/integration-review.md) for all thirteen component boundaries and acceptance evidence. Browser Chromium verification is separate from actual OBS, mobile Twitch, real chat and native raid acceptance.
