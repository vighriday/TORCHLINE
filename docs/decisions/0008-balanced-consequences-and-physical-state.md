# ADR 0008: Reachable failure, consequential cooperation and persistent physical state

Status: accepted for implementation, 2026-10-26. Supersedes the numerical `ark-v1` design; retains ADR 0001 and 0006 boundaries.

The executable baseline audit finds no catastrophic endpoint among 32 authored paths. Add cumulative, previewable damage, persistent leaks and navigation-dependent landing risk. Colony viability includes population and supplies, so preserving one resource cannot erase every sacrifice.

Viewer solutions change the same authoritative state as creator choices: shield repair affects later damage, a completed work order stops future leaks, and route discovery unlocks precision salvage. Rewards are globally bounded and recorded once. They do not depend on audience size, a raid, runtime AI or animation completing.

Persist physical system condition and scars separately from resource reserves. Include causal event IDs and community provenance. Custody changes cannot reset those values. Reconstruct state through deterministic accepted-action replay and verify event effects against snapshots.

Exhaustively enumerate authored decisions and discrete challenge outcomes, including valid partial repair work orders. Record affordability exclusions and early terminals. Allocation/timers are separate policy dimensions and must have their own tests before claiming exhaustive combined coverage. Keep population-zero failure as an invariant; do not claim it is reachable in the authored first season if enumeration does not establish that.

Accept this balance for the functional slice after all three ending classes and material challenge benefits have executable witness paths. Numerical reachability is not evidence of fun; creator/viewer playtesting remains required.
