# v0.1.0-preview.1

TORCHLINE's first tagged development preview: a saved cooperative survival game for Twitch, where communities shape the same Ark and can eventually pass it between consenting creators through a genuine raid.

## Playable now

- Five chapters with cooperative puzzles, repair tasks, resource allocation and three possible endings.
- Lasting ship damage, repairs, history and saved progress; the full season works on one channel.
- The integrated 3D game screen, accessible fallback and read-only spectator/overlay view.
- Broadcaster/bot authentication, signed-event handling, chat processing and the prepared raid-transfer protocol.
- Recovery, bounded input handling, history queries, encrypted local backup/restore and reproducible release-container tooling.

## What the evidence establishes

The preceding source passed 97 automated tests, 11 browser journeys, proof/fixture consistency and restricted-container smoke. This release is published only after the tagged source passes its own Verify workflow. [Verification runs](https://github.com/vighriday/TORCHLINE/actions/workflows/verify.yml).

Real Twitch account grants, required event connections, public HTTPS browser access and a read-only browser overlay were checked on October 28. Recorded gameplay is a saved simulation. These are separate kinds of evidence.

## Before a live launch

Genuine gameplay chat, visible bot replies, native OBS and a consenting two-broadcaster raid/inheritance session still need live acceptance. Permanent hosting, remote recovery and extended deployed testing remain open. This preview is not a production-ready or stable-API release.
