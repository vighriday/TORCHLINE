# v0.1.0-preview.4

Play it in a browser. This development preview puts the practice game and the Judge Arena relay on a public link that needs no install and no Twitch account, and it fixes a Twitch detail that would have blocked a native raid offer.

## What changed

- **Hosted practice demo: <https://torchline-demo.onrender.com>.**
  - The unchanged production server in simulation mode, with PostgreSQL on loopback inside the same container (`deploy/demo/`, [ADR 0039](https://github.com/vighriday/TORCHLINE/blob/v0.1.0-preview.4/docs/decisions/0039-hosted-practice-demo.md)).
  - Fresh secrets and a fresh database on every start; no Twitch credentials exist in it.
  - A one-click Render Blueprint (`render.yaml`) deploys it on a free web service.
  - CI builds the image on every push and plays practice sign-in and Ark creation against it in production mode. On 2 November the Judge Arena relay ran end to end on the hosted copy.
- **Raid readiness fix.** Twitch echoes a `channel.raid` subscription's unused direction as an empty `from_broadcaster_user_id`. The strict condition comparison rejected that shape, so raid readiness never became true and an offer could not be prepared. Empty provider condition values are now dropped on parse, and the provider fixture reproduces Twitch's real shape.
- **Flaky test fixed.** An episode-clock test backdated two columns with two `clock_timestamp()` calls that drift apart by microseconds; it now uses one statement timestamp.
- **Documentation.** The README leads with the browser demo; the status table separates the hosted practice demo from live hosting, which is still open. Codex's working dates are stated as 26–30 October to match the session.

## Upgrading

No new migrations. Existing databases at migration 014 run this build unchanged.

## Evidence and limits

- **Automated checks:**
  - Vitest: 164 tests in 43 files against real PostgreSQL.
  - Playwright: 25 browser journeys, including the full two-game relay.
  - Release-container, compose and hosted-demo-image smoke tests.
  - The Verify workflow on `main`.
- **Live Twitch:** on 30 October 2026, three genuine viewer chat commands arrived as signed EventSub notifications and were saved as gameplay events on a live Ark.
- **Bot replies:** on 2 November Twitch accepted two test sends (`is_sent: true`, no drop reason) that an anonymous viewer connection never received. Replies stay paused; gameplay never depends on them.
- **Still open:**
  - a recorded overlay update from live chat;
  - an attested live LIVEWIRE result;
  - a native raid between two consenting broadcasters;
  - bot replies that viewers can see;
  - permanent live hosting.
- The demo is disposable: a free service sleeps when idle, and every wake starts a fresh database. The Judge Arena raid proof is simulated and labelled as such.
